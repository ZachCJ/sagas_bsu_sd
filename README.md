# capstone-template
BSU CS481 Capstone project template

## Instructions on executing a TypeScript program
Navigate to the directory the file is located in and then compile the code with the command `tsc <filename>`--or `tsc <filename> --ignoreConfig` if you run into errors. This will create a file with the same name, but with the JavaScipt extension instead. Once the program has been compiled, run the command `node <filename>` and the program will then run.

## Instructions on running tests
### vitest
When using vitest to run your tests, simply navigate to the correct directory and run either `npm run test`, `yarn test`, or `pnpm test`, depending on your package manager. 

Another way you can run the tests in vitest is navigate to right directory where the test.sh file is located in and then run the command `./test.sh` in the termianl and it will run every test.
